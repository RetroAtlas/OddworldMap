# 104. Cut the stylesheet into partials linked in name order

**Status:** shipped 2026-11-10 · **Effort:** small: three commits, each proven by a join or a cascade check · **Where:** anywhere · **Filed:** 2026-11-10, from a reading of the stylesheet's structure, its cascade and every reference to it

## What and why

`public/css/main.css` was held by no size cap ([101](item-101-file-size-caps.md) covers the modules, the tests and the tools): 2,020 lines on 2026-11-10 (`wc -l`), two and a half times the cap a module or a spec is held to, and the reason the caps give, that a file is read whole, applies to it as to any of them: an agent's whole read stops at 2,000 lines, so the reduced-motion block at its end was the part no session saw. It already fell into subjects, each opened by a heading comment or by a bare selector after the previous rule's brace, so a cut at those seams moves every line verbatim and in order and changes nothing the page computes: the cascade is the order of the rules, and files linked in the order they were cut carry it exactly. Partials also say where a rule goes by file name, which a 2,020-line file with grep as its only index did not.

## Decided

- Nine flat partials, named by page region, each `NN-word.css` with its rank in the cascade first: `10-base.css` (the tokens, the resets, `.sr-only`, the body), `20-sidebar.css`, `25-search.css` (the sidebar's search box, scope bar and results), `30-map.css` (the map, the canvas, the world graph), `40-readouts.css` (tooltips, corner readouts, minimap, toasts, route readout), `50-panels.css` (screen list, edit form, numbers panel, the list rows they share), `70-chrome.css` (the controls over the map, the menu, embed mode, the place chip, the path details), `80-dialogs.css`, `90-narrow.css` (the narrow drawer and reduced motion). The sections are the file's subjects read off its headings and the page, not marks the file carried: of the eight blank lines it had, three sat at a cut; the other five cuts land after a closing brace, on a heading comment or on a bare selector.
- The link order is the cascade, and the names carry it: [tests/unit/stylesheet.test.js](../tests/unit/stylesheet.test.js) requires `index.html`'s stylesheet links, in document order, to equal the `.css` files under `public/css` sorted by name, each once, every href under `css/`, every name of the shape above. The order is load-bearing in four places, measured on 2026-11-10 by a parse of every rule with its specificity: the narrow partial last, since it restates selectors first written in six of the other eight partials at equal specificity, setting properties they set; the map after the sidebar (`body.editing #editTools` against `body.graph #editTools`, both (1,1,1), the graph meant to win); the dialogs after the panels (`.listhead` and `.tc-fhead` padding on the type card's heads, both (0,1,0)); the chrome after the readouts (`#tip .e` against `#tip .edited` and `.released`, both (1,1,0)). Every other overlap across sections resolves on specificity, and the base and search partials carry no dependency either way.
- A new partial takes a free number between what it must follow and what must follow it, a multiple of five where one is free, with no rename: every future partial is an insert, since the narrow block is pinned last by the cascade and the tokens first, and the stylesheet's history (92 commits since it left `index.html` on 2026-07-16; seven of the nine subjects present that day, the other two within three days, none since) says inserts will be rare but never appends. The ranks run in tens for that reason; nothing can follow 90, so no third digit is ever needed, and 00 to 09 stay free ahead of the base for a tokens partial, the one thing that could ever precede it.
- Every line verbatim, in one commit with every reference the split forces: the links, the test, the `public/css` row at 800 in `sizes.test.js`, `graphsvg.test.js` reading the partials joined in name order (it reads the tokens from the base and the graph's rules from the map, and requires each token declared once), the docs and this record. The proof, run before the commit and not kept as a test since the old file is then gone: the partials joined in link order, blank lines stripped, equal the old file with blank lines stripped (the three cuts on a blank line lose it, Prettier stripping a trailing blank line), and `npm run pixels` against the parent paints alike.
- A rule joins its surface's partial and a shared class stays in the partial where it first appears; the shared vocabulary [docs/stylesheet.md](../docs/stylesheet.md) describes is spread over the sidebar, the panels and the dialogs by that rule, and gathering it into one partial would be a cascade change needing a proof of its own, computed styles of fixed page states before and after, not a move.
- Three rules the cut left where the file had them stand with their surface: `.muted`, worn by the sidebar's game name alone, in the sidebar after the heading's button; `#noscript`, the map's fallback text, in the map after the canvas; and `.shead`, the search results' heading's own modifier of the shared `.listhead`, in the search partial. Nothing but the base's `*` reset matches any of the three elements, and the base precedes every partial, so no rule changes rank against another.
- The search partial stands at 25, beside the sidebar whose search box it styles, where the file had held the search 747 lines from the sidebar: every selector in it but `.shead` is rooted in `#searchBox`, `#scopeBar` or `#searchResults`, no rule in the three partials it precedes names those ids, `.shead` sets `justify-content` alone, which no rule on the results' heads sets, and the panels' `.listhead` and `.rowbtn`, which reach the results, do so at a specificity the order never decided.
- Loading, measured on 2026-11-10 against the live site: HTTP/2 through Cloudflare over GitHub Pages, `max-age=600` on every file; nine links in the first 3 KB of the page open nine streams on the one connection at once, so first render waits for the last as it waited for one, and the cost is bytes, 3.9 KB more gzip (10.3 KB whole, 14.1 KB summed, at `gzip -9`) and the headers of eight more responses. The deploy-boundary window, 600 s at the edge and 600 s in the browser, is the one the site lives with for `index.html` against its modules; a stale partial beside a fresh one fails softer than a stale module, an unmatched rule rather than a thrown error.

## Ruled out

- Leaving the stylesheet whole and exempt from the caps: grep finds a selector in nine files as in one, and the split buys whole reads of 76 to 426 lines and the size tripwire.
- `@layer`, a layer a partial, to make the order explicit: a lower-specificity rule in a later layer beats a higher one in an earlier layer, so it is not the same cascade; five reachable inversions were found (the toggles' keycaps against `kbd`, the chip row and the route bar in graph mode, three close buttons against `.closebtn`, the search results' notes).
- One `main.css` of `@import` lines: the preload scanner cannot see an `@import`, so first render waits an extra round trip on every visit while the nine files still ship.
- A concatenation at deploy: `public/` is served as it is and the suites test that same tree.
- Four partials: one of 763 lines, about 1.6 KB of gzip saved, and the subjects that grow merged (the sidebar, the panels and the search took 151 of the 184 lines added in the 60 days to 2026-11-10, the chrome and the dialogs 29 of the rest).
- Mirroring the folders under `public/js`: a stylesheet groups by page region and the modules by import direction, and a `panels` partial would start near 1,000 lines.
- Folders under `public/css`: [101](item-101-file-size-caps.md) rules folders out as a way to keep a file small, and nine files need none.
- Plain `01` to `09` or three digits: a rename on every insert, or 99 slots a gap that nothing needs.
- A committed test that the join equals the old file: after the commit its only oracle is a git object, and it would freeze the stylesheet at the split.
- A tokens partial of its own now: the page reads the tokens by computed style, only the graph test reads the file, and it needs the map's rules too.

## Shipped

Landed on 2026-11-10: nine partials holding every line of the old file verbatim, the join in link order equal to it but for three blank lines, the three rules that stand with their surface and the search partial's place; `npm run pixels` against the parent draws all 29 views alike, the unit and browser suites are green, and a one-off comparison of every element's computed style in six page states, before the cut and after, found no difference.
