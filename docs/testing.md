# Test suites

## `python3 -m unittest discover -s tools/tests`

- No disc image is needed, and the sidecar reproducibility tests run from the committed caches; only the tests that probe the checkout itself (the member-type parser pair and the four cache freshness checks) skip, and only where no checkout is configured or found — `$ODDWORLD_DECOMP` naming a path that holds none fails them instead, a named location being an assertion rather than a hint — and the tests that encode through oxipng skip where none is on PATH, which is every CI run. CI clones the pinned revision into `$ODDWORLD_DECOMP`, reading `DECOMP_COMMIT` and `AO_COMMIT` off `paths.py` and fetching both by SHA, which is what makes the six run in CI; a clone step gone missing fails them rather than skipping, the variable being set either way.
- A parser reached only through a nested helper (AE's `positional_rows`, the enum body loop) can't be tested until it's hoisted.
- `test_sprites.py` pins each sprite codec against a frame lifted off a disc (`fixtures/sprite_frames.json`, with the sha1 of the rows it decodes to), the animation-table walk over a synthetic chunk, the texel alpha states, the packer, the shape of the curated animation list and the random-table search over a synthetic executable; the atlases themselves reproduce only on a disc machine, like the cameras.

## `npm run test:browser`

- `anchors.spec.js` is the [alignment anchors](viewer-geometry.md#alignment-anchors) as a gate, each pinned twice: its geometry as literals — where the marker draws inside its own 368×240 screen, hand-verified against the artwork once and frozen, never regenerated from `model.js`, which is what they test — and its pixels colour-agnostically, the screen's canvas region matching the committed cam PNG away from the markers and differing from it on the pinned outlines. A transform regression fails the numbers at zero tolerance; a painter regression fails the pixels.
- `smoke.spec.js` covers what breaks visibly: boot paints a map with a clean console, a view permalink lands where it points and `viewHash()` reproduces it (a plain view hash is never rewritten, so asserting `location.hash` survived would be vacuous), a click on a door follows it, `?embed=1` hides the chrome, a search Enter moves the view (to a plain view hash — a search jump writes no object token), and a settings toggle survives a reload.
- `graphexport.spec.js` drives the world graph's two save buttons through the real anchor-click download, per game: the filename, the SVG parsing whole with one box per node the diagram shows, Exoddus's ender caption reaching the string, and the PNG header reading the layout `worldgraph.test.js` pins with the title band above it, doubled; Oddysee's reads a background pixel back, because a blank canvas encodes to a perfectly good PNG.
- `reliveexport.spec.js` presses the JSON export button through the real sidecar fetch and download, per game from the path a game-only hash boots: the filename, the landed document hashed against `tests/fixtures/relive-digests.json`, no sidecar request before the press and exactly one across two, the button's accessible description matching its tooltip word for word, a sidecar that failed to parse fetched again on the next press, and a doctored one refused with a toast naming the property and no download fired — the sidecar URL and the button's wiring are the two seams the Node digest suite cannot see.
- `motion.spec.js` works the sleeping slig at the mouth of the Mines and a few neighbours over the shipped data: Objects as themselves turned on reads the canvas under the slig's marker before and after (the sidecar fetched once and only on the turn, the pixels changed, the console clean); the sidecar held back leaves bare artwork where the sprite will stand and an export unready; a sidecar that fails is asked for once and the objects fall back to markers until the toggle retries; Patrols stays greyed, refusing its `b` key with a toast, until the objects are shown and the Animate setting is on; a Zulag 4 slig is hovered where it has walked to and not where it was placed; the pens draw their posts with the markers off; the Mines lift's top wheel is drawn at its pulley, screens above the lift's rect; over the lift's rope the hover names the drawn lift before the unseen stop beneath; a Paramonian rolling ball answers the hover over its whole image; Markers for the rest is greyed until the objects are shown, and off, a bound's marker leaves the map while an open door, a well, a hand stone and an LCD screen stay present, a wire's far end only while the wiring is drawn; an arrival only an arrow points at, a Necrum bird portal's exit, stays while the arrows are drawn; the kept set follows the filters, that exit joining it as Doors / Transitions comes on and leaving as it goes off; the scenery carries no label until the setting asks; Dim backgrounds dims a foreground mask over the sprites to the shade of the screen beneath, and leaves it bright when off; the `o` key flips the checkbox both ways while the shortcuts dialog names it; and the clock runs with the objects shown, stops with the Animate setting, counts the patrols from their toggle's turn and starts the scene over on a path change.
- The suite runs the engine's clock: no reduced-motion preference is set on the browser context, so sprites animate and patrols walk in every spec, and a spec that depends on movement waits on `patrolTick()` or `sceneTick()` through the page's own motion module, never on wall time.
- The specs probe the page through its own module singletons (dynamic import resolved against `location.href`) and settle the way `export.js` does (`preloadPath`, `artworkReady`, a synchronous `draw()`), once the canvas width has held still for three frames, since the sidebar's boot slide shrinks the canvas and recentres the view over the first frames; `deviceScaleFactor` is 1 for every spec, set once in the config; the anchor spec, the one that compares pixels against the artwork, additionally pins the levers that comparison needs: zoom exactly 1, `?embed=1`, every show/cats key seeded explicitly through `owm:view`, and the mouse never moved. In a `waitForFunction` predicate keep to synchronous reads (`location.hash`) — an async predicate returns a Promise, which the poller takes as truthy at once, so the wait resolves with the promise's first value instead of polling.
