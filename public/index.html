Settings

Saved on this device

Keeps the Display toggles and Objects filters across visits.
Reopens the map where you left off. A shared link always wins.
Stores the app and the screens you visit, so the map opens and works with no connection at all. Turning it off removes the stored app and artwork.
Store every screen now, and places you have never opened work offline too.

Objects as themselves

Runs the engine's clock under the sprites: mines flash, working Mudokons scrub, saws stroke. Off, every sprite stands on its first frame.

Buttons and names

Game, level and path buttons list their full in-game names.
Lists a level's paths in the order a player meets them rather than the order the games store them.
Exoddus stores 25 extra copies of areas that only the demos playing on its title screen ever visit. There is no way to walk to any of them in the game.

Objects and fields

Clicking or tapping a screen (anywhere that isn't a followable object) opens a panel listing everything on it.
Adds a Fields panel to the sidebar for picking, per object type, which of the game's stored fields (Slig shooting behaviour, patrol timings, and more) show in tooltips and the screen list.
Adds an Edit objects button to the sidebar (or press e): a click on a marker selects it, and a panel changes any field the game stores for it, with what the disc shipped beside anything you change.
Field values show as the raw numbers the game stores (1/0, ...) instead of the translated text (left/right, patrol, true/false). For custom-level builders and the curious; search matches whichever representation you're viewing.

About this map

oddworldmap.com is an unofficial, fan-made interactive map. Oddworld, Mudokons, Glukkons, and all related characters and designs are registered trademarks and copyrights of Oddworld Inhabitants, Inc. This project is not affiliated with, endorsed, or sponsored by Oddworld Inhabitants.

Part of RetroAtlas, a collection of interactive maps of classic games.

Every screen, object, sprite and collision line is read from the game discs, and the sprites stand and move by the game's own object rules, ported from the decompilation with no player in the world; an object you edit in the browser is a layer over that, marked wherever it shows and never carried by a link. Formats reverse-engineered by the AliveTeam / alive_reversing project.

Every level also has a plain page of its own, listing its paths with links into the map.

A path can be saved as the AliveTeam level editor's JSON: a description of its objects and collision lines, carrying no artwork and no game code. An unedited path's file is what this map is checked against; a path you have edited saves under a name that says so and describes your edits. Importing either into your own copy of the game drops that path's foreground masks.
